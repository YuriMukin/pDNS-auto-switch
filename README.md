# pDNS Auto Switch

Небольшое Android-приложение для переключения Private DNS из шторки быстрых настроек.
Полезно, если собственный DNS-провайдер нужен в одних сетях и мешает работе в других.

## Возможности

- Плитка **Smart DNS** и кнопка в приложении включают сохранённого провайдера или выключают Private DNS.
- Адрес провайдера сохраняется при переключении.
- Состояние берётся из настроек Android, включая изменения, сделанные вне приложения.
- Светлая и тёмная темы следуют настройкам телефона.
- Системные цвета обоев Material You или спокойная бирюзовая палитра на выбор.
- Проверка имени подключённого Wi-Fi и локальный список доверенных сетей.

Приложение работает без root, Shizuku и локального VPN. Постоянно работающий фоновый сервис
не требуется. Автоматического переключения по Wi-Fi пока нет.

## Требования

- Android 13 или новее.
- Настроенный в Android провайдер Private DNS (имя хоста DNS-over-TLS).
- Компьютер с ADB для однократной выдачи разрешения после установки.

Приложение не предоставляет DNS-сервер: нужно использовать своего провайдера.

## Установка и первый запуск

1. Соберите APK по инструкции ниже и установите его на устройство.
2. Откройте Android Settings → «Сеть и интернет» → «Персональный DNS» и сохраните имя хоста
   своего провайдера. Названия пунктов могут отличаться в разных прошивках.
3. Включите USB-отладку, подключите телефон к доверенному компьютеру и разрешите отладку.
4. Выдайте разрешение приложению:

   ```shell
   adb -s <serial> shell pm grant io.github.sorjo.pdnsautoswitch android.permission.WRITE_SECURE_SETTINGS
   ```

   Замените `<serial>` идентификатором своего устройства из `adb devices`.

5. Вернитесь в приложение и нажмите «Добавить плитку». Её положение можно изменить в редакторе шторки.

ADB не должен оставаться подключённым для работы плитки. После удаления и повторной установки
приложения разрешение нужно выдать заново.

## Использование

Нажатие **Smart DNS** переключает выбранного провайдера и выключенный режим. Долгое нажатие
открывает приложение. На заблокированном телефоне перед изменением потребуется разблокировка.

Режим Android «Автоматически» отображается отдельно: нажатие включает сохранённого провайдера.
Если провайдер не указан или разрешение не выдано, приложение предложит завершить настройку.

«Включён» означает выбранный режим Private DNS в Android; доступность DNS-сервера не проверяется.
Приложение не отправляет собственные DNS-запросы и не читает изображение обоев для оформления.

## Доверенные Wi-Fi

В разделе «Доверенные сети» нажмите «Проверить подключённую сеть». Android потребует
точную геопозицию при использовании приложения и включённую системную геолокацию:
имя Wi-Fi (SSID) считается данными, связанными с местоположением. Координаты приложение не запрашивает.

После успешного чтения SSID сеть можно добавить в локальный список, а затем удалить из него.
Перед добавлением подключение проверяется ещё раз. Неизвестные/скрытые имена не сохраняются.
SSID — имя сети, а не уникальный UUID; одноимённые Wi-Fi пока не различаются.

Проверка выполняется по нажатию и прекращается при уходе с экрана. Сканирования окружающих
сетей нет. На этом этапе список **не изменяет DNS автоматически**.

## Сборка

Проект использует Kotlin, XML Views и Material 3. Нужны Android Studio или Android SDK,
JDK 25, SDK Platform 37 и Build Tools 36.0.0. Минимальный API — 33, целевой — 37.

Откройте корень проекта в Android Studio и дождитесь Gradle Sync. Настройте локальный путь
к SDK, если среда не определила его автоматически, и JDK для запуска Gradle.

В PowerShell из корня проекта:

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

В Linux/macOS используйте `./gradlew` с теми же задачами.
Debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Для распространения используйте [подписанную release-сборку](docs/release-build.md).
