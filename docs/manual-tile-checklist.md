# Проверка ручной плитки на Pixel / Android 17

До проверки убедиться, что сохранён адрес собственного провайдера Private DNS.
Зафиксировать исходный режим, чтобы вернуть его после тестирования.

- Чистая установка без WRITE_SECURE_SETTINGS: экран показывает инструкцию, переключатель недоступен.
- Добавить плитку кнопкой. Проверить отказ от добавления и повторное добавление уже существующей плитки.
- Нажать плитку без разрешения: открывается экран настройки; DNS не изменяется.
- Выдать разрешение командой из приложения. Вернуться на экран и проверить обновление статуса.
- Нажать плитку при `hostname`: режим становится `off`, адрес провайдера остаётся прежним.
- Нажать ещё раз: режим возвращается к `hostname`, тот же провайдер указан в настройках Android.
- Сверить активность и подпись плитки с системными настройками.
- Изменить режим и адрес провайдера через Android Settings; открыть шторку и приложение, проверить обновление.
- Выбрать режим Android «Автоматически»: плитка показывает отдельную подпись; нажатие включает сохранённого провайдера.
- Удалить адрес провайдера: приложение не должно записывать `hostname`, плитка открывает настройку.
- Долгое нажатие плитки открывает приложение.
- На заблокированном устройстве изменение требует разблокировки; отмена ничего не меняет.
- Отозвать разрешение через `adb shell pm revoke io.github.sorjo.pdnsautoswitch android.permission.WRITE_SECURE_SETTINGS`:
  следующее нажатие не приводит к падению и открывает настройку.
- Повернуть экран, увеличить шрифт, проверить прокрутку и отсутствие перекрытия системными панелями.
- Закрыть приложение, завершить процесс, снова открыть шторку: состояние считывается заново.
- После перезагрузки и после обновления APK проверить сохранение разрешения и работоспособность плитки.

Это проверки на реальном устройстве; JVM-тесты не доказывают, что прошивка разрешает запись
Settings.Global или что SystemUI корректно отображает плитку.

## Выполненная проверка 17 октября 2026

- `assembleDebug`, `testDebugUnitTest`, `lintDebug` — успешно; 11 JVM-тестов без ошибок.
- Lint: одно предупреждение о новой версии Gradle; ошибок нет.
- На эмуляторе Android 17/API 37 установлен debug APK, приложение запускается без падения.
- Плитка добавлена в SystemUI через тестовую команду `cmd statusbar add-tile`.
- Без WRITE_SECURE_SETTINGS нажатие плитки открывает приложение и не меняет DNS.
- После обычного `pm grant` плитка переключает `off → hostname → off`, сохраняя `dns.google`.
- При пустом провайдере `hostname` не записывается.
- После `pm revoke` нажатие открывает приложение, режим не меняется, падений нет.
- Из режима `opportunistic` нажатие переключает на сохранённого провайдера.
- Стартовый экран проверен по скриншоту эмулятора.

Кнопка системного добавления плитки, долгое нажатие, защищённый экран блокировки,
перезагрузка и особенности реального Pixel остаются в ручном чек-листе выше.
