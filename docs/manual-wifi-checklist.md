# Проверка списка доверенных Wi-Fi

Этот этап только читает подключение и редактирует локальный список. Ручная плитка DNS
остаётся независимой. Автоматического переключения DNS нет.

## Сценарии

- При первом открытии приложение не запрашивает геолокацию самостоятельно.
- «Проверить подключённую сеть» объясняет назначение разрешения и вызывает системный диалог.
- Отказ, приблизительная геопозиция и запрет повторного запроса обрабатываются без падения;
  есть переход в разрешения приложения.
- При точной геопозиции, включённой системной Location и подключённом Wi-Fi отображается SSID.
- При выключенной Location показана причина и переход в настройки; приложение не включает её само.
- Нет Wi-Fi: показано отсутствие доступного подключения и, если возможно, текущий тип сети.
- Если Android скрывает SSID, сеть нельзя добавить.
- Добавление повторно проверяет подключение. При изменившемся SSID старый результат не сохраняется.
- Повторное добавление того же SSID не создаёт дубликатов.
- Список сохраняется после перезапуска процесса и обновления APK с той же подписью.
- Удаление подтверждается и изменяет только локальный список, не системные сети Wi-Fi.
- Уход с экрана отменяет текущую проверку; устаревшие кнопки добавления убираются.
- Проверка и редактирование списка не меняют `private_dns_mode` и `private_dns_specifier`.
- Светлая/тёмная тема, динамическая палитра, длинные имена и крупный шрифт не ломают разметку.
- При VPN проверять доступные физические Wi-Fi отдельно. Это ещё не алгоритм выбора сети для Auto.

SSID — имя сети, не UUID и не криптографическое доказательство её подлинности. Регистр,
Unicode и пробелы значимы. Сети с одинаковым SSID пока не различаются.

## Выполненные проверки

На эмуляторе Android 17 проверены отказ и выдача разрешения через системный диалог,
чтение SSID, добавление, сохранение после перезапуска процесса, удаление с подтверждением,
светлая и тёмная темы. JVM-тесты проверяют нормализацию и постоянство списка.
Также проверены выключенная Location, отсутствие Wi-Fi и неизменность режима DNS и провайдера до/после проверок. Debug и подписанная release-сборка проходят 16 JVM-тестов и Lint (0 ошибок, 10 предупреждений). Подпись release совпадает с предыдущей сборкой, выравнивание APK проверено.

На физическом Pixel новая возможность пока не проверена. Работа в фоне, после reboot,
под VPN и при нескольких одновременно доступных Wi-Fi ещё требует отдельной проверки.
Чтение SSID в открытой Activity не доказывает пригодность решения для фонового сервиса.
