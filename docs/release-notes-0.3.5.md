# pDNS Auto Switch 0.3.5 — автоматическое переключение Private DNS

К ручной кнопке и плитке Smart DNS добавлено автоматическое управление DNS по подключённой сети.

## Что нового

- **Доверенные Wi-Fi.** Приложение читает имя подключённой сети и позволяет сохранять и удалять
  сети в локальном списке доверенных.
- **Режим Auto.** На доверенном Wi-Fi Private DNS выключается; в остальных сетях включается
  сохранённый провайдер. Если имя Wi-Fi недоступно, сеть не считается доверенной.
- **Фоновое наблюдение.** Сервис запускается пользователем из приложения и отслеживает изменения
  сети после закрытия экрана приложения, в том числе при выключенном экране телефона.
  Наблюдение можно использовать отдельно, оставив Auto выключенным.
- **Пауза после ручного переключения.** Нажатие кнопки или плитки сразу переключает DNS и ставит
  включённый Auto на паузу. Доступны **1, 5, 10, 15, 20, 25 или 30 минут**, по умолчанию — 10.
  Выбор сохраняется между запусками и применяется со следующего ручного нажатия; текущая пауза
  сохраняет свой срок. Повторное нажатие начинает отсчёт заново, смена сети паузу не отменяет.
  После её завершения Auto заново проверяет сеть и применяет актуальную политику.
- **Статус Auto.** В приложении отображаются состояние автоматизации и время окончания паузы.
  Плитка продолжает показывать фактическое состояние Private DNS в Android.
- **Локальный журнал.** По желанию записываются сетевые события, рекомендации и результаты
  автоматического применения. До **2500 записей** сохраняются между запусками; при заполнении
  удаляется старейшая десятая часть. Доступны отключение записи, очистка и экспорт UTF-8 файла
  `pDNS auto switcher.log` в Downloads. SSID, BSSID, IP и имя DNS-провайдера в журнал не попадают.

Auto дожидается стабилизации сетевых событий, сохраняет имя провайдера и проверяет результат
изменения в настройках Android. Повторные события не инвертируют уже установленный режим.
При отсутствии разрешения, недоступном провайдере или ошибке применения Auto выключается
с сообщением.

## Как включить Auto

1. Настройте провайдера DNS-over-TLS в Android и предоставьте приложению право изменять Private DNS.
2. Разрешите точную геопозицию при использовании приложения и включите системное местоположение:
   Android требует их для доступа к имени Wi-Fi. Координаты приложение не запрашивает.
3. Проверьте подключённый Wi-Fi и добавьте нужные сети в доверенные.
4. Включите Auto в разделе наблюдения. При необходимости выберите длительность ручной паузы.

Если право изменения DNS ещё не выдано, выполните через ADB:

```shell
adb -s <serial> shell pm grant io.github.sorjo.pdnsautoswitch android.permission.WRITE_SECURE_SETTINGS
```

Замените `<serial>` идентификатором устройства из `adb devices`. Уже выданное разрешение
при обычном обновлении повторно выдавать не требуется.

## Работа и обновление

Требуются Android 13+ и настроенный провайдер DNS-over-TLS. Ручная кнопка и плитка по-прежнему
работают без постоянного фонового сервиса. Для фоновой автоматизации нужен явно запущенный
сервис; root, Shizuku и локальный VPN не требуются.

Выключение Auto оставляет текущий режим DNS. Остановка сервиса завершает Auto и паузу.
После завершения процесса или перезагрузки Auto нужно включить заново; автозапуска нет.
Во время ручной паузы сервис продолжает наблюдение, приостановлены автоматические изменения DNS.

APK устанавливается поверх предыдущей подписанной версии: application ID и ключ подписи
сохранены, versionCode увеличен до 7.
